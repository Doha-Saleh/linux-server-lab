# Linux Server Lab
## Technologies & Tools
- Ubuntu Server
- Oracle VirtualBox
-Linux Command Line
- SSH
- Apache Web Server
- UFW Firewall
## Tasks Completed
-Created and configured an Ubuntu Server virtual machine
- Cnfigured hostname and network connectivity
- Created users and groups
- Configured Linux file permissions
- Installed and configured SSH
- Installed and configured Apache Web Server
- Created a custom HTML webpage
- Configured UFW firewall rules
- Checked Apache access logs
- Created a basic backup of the web server files
- Configured SSH and Apache to start automatically
## Learning Goals
The main goal of this project was to gain practical experience with Linux system adminstration, networking, user management, permissions, server services, firewall configuration and basic troubleshooting.
